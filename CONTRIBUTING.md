# Участие в проекте

## Лицензия

Оригинальные исходники проекта распространяются под
[CERN Open Hardware Licence Version 2 - Permissive](LICENSE) (CERN-OHL-P v2).
Отправляя pull request или патч, вы подтверждаете, что имеете право передать
изменение под этой лицензией.

Сторонние библиотечные материалы перечислены в
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). Новый сторонний символ,
посадочное место или 3D-модель добавляйте только вместе с записью о его
лицензии, правообладателе и источнике.

## Инструменты

- KiCad **10** (формат файлов `version 20260306`); выгрузки сделаны
  `kicad-cli` 10.0.7.
- Python 3 — только для `scripts/export_manufacturing.py`, без сторонних
  зависимостей.

## Правила работы

- Правила проектирования схемы — в [CLAUDE.md](CLAUDE.md), расстановки и
  трассировки платы — в [RULES.md](RULES.md).
- Перед правкой файлов скриптами KiCad должен быть закрыт (нет `*.lck`).
- После правки схемы: ERC без ошибок и предупреждений; после правки платы:
  DRC без замечаний, без несоединённых цепей и расхождений со схемой.
- Коммиты — Conventional Commits: заголовок на английском, тело на русском.

## Производственные файлы

Когда меняются схема или плата, в том же изменении перегенерируйте выгрузки:

```text
python3 scripts/export_manufacturing.py
```

Скрипт обновляет `manufacturing/` (Gerber, сверловка, BOM и CPL в формате
JLCPCB) и `docs/` (PDF схемы, рендеры платы). Ключ `--no-render` пропускает
3D-рендеры (они самые долгие).

## Перед pull request

- Добавьте в [CHANGES.txt](CHANGES.txt) запись с датой и кратким описанием
  изменений; прежние записи не удаляйте (требование CERN-OHL-P v2, п. 3.3(b)).
- Если вы вносите вклад, охраняемый авторским правом, добавьте себя в
  [AUTHORS.md](AUTHORS.md).
- Проверьте diff на случайные бэкапы, файлы блокировок и несвязанные правки.
